# Raw Preprocessing Inputs

This folder contains the raw inputs used by `scripts/preprocess_data.py`. These files make GONetView reproducible without any dependency on another local project.

## Expected Layout

```text
data/raw/go-basic.obo
data/raw/annotations/*.gaf.gz
```

With these files present, GONetView can regenerate `frontend/public/data/` from this project alone.

## Updating Data

1. Replace `go-basic.obo` and/or the relevant `*.gaf.gz` files.
2. Record the new source, version, and download date here.
3. Regenerate browser data:

```powershell
.\.venv\Scripts\python.exe scripts\preprocess_data.py
```

4. Run checks:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
npm.cmd --prefix frontend test
npm.cmd --prefix frontend run build
```
